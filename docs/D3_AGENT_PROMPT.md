【强制计算口径】
1. 每个t日因子只用t日日终可知信息和当日历史股票池；不能用今天成员回填历史。信号最早下一交易日开盘执行，不能t收盘计算又以同一收盘价成交。
2. h=1/5/20交易日；后续收益标签=同口径adjusted_close(t+h)/adjusted_open(t+1)-1。h=1是下一交易日开盘到收盘。按交易日历定位，不遇到停牌就顺延。
3. 标签只供评价，单独取数；退出日不能超过锁定的评价截止日，不进入信号/候选/手数计算或AI选股输入。模型不得更改可信身份、角色或研究日上限。
4. 缺因子、缺价格、停牌、除权口径问题、退市无退出值、历史不足和未到期分别保存原因，不补零、不静默删除失败样本。
5. IC用Pearson，Rank IC对两边平均秩计算Pearson；按股票代码严格配对。正式计算每日至少10对；零方差/不足为空，不能记为0。ICIR=有效每日IC均值/样本标准差，不能计算时为空，不无依据年化或声称显著。
6. 分组默认5组且每组至少5只；15至24只降3组，不足15只不分组。相同因子值不能拆开，按完整平值块作最接近等量的可行分割，具体规则见计划；条件不满足时记录原因。19只教学股票不能声称是有效的大样本研究。
7. 每组平均h日收益是同批持有标签，不是实盘回测。重叠h日收益不能逐日复利成曲线；理论高低组差不是可卖空策略。
8. 原始IC方向固定；策略高值/低值优先另存，不看完测试后自动翻方向或搜索最佳参数。数据快照、公式版本、日历/股票池和计算版本须固定。

【费用功能】

A股模式：买/卖佣金、最低佣金、包含关系、按成交日适用的税费快照、滑点。
CUSTOM_LIQUIDITY模式：maker_rate、taker_rate及ALL_TAKER默认或ALL_MAKER假设。它是收费模拟，底层仍是现有市场/日线撮合，不意味着实现了加密资产市场。maker/taker不是买/卖，也不是限价/市价的简单映射。没有盘口就不能声称真实识别，首版不模拟返佣/部分成交。
