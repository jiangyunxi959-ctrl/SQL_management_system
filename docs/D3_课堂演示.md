# D3 课堂演示

先确认数据库在 `127.0.0.1:55436`，`.env` 指向已经安装 D3 的库。教学演示用正式样本或 `zhishi_d3_review_20261029_sample`。外部财报只在名字里带 `real` 的副本里看。

## 启动

```powershell
.\.venv\Scripts\python.exe -m streamlit run app/ui/main.py --server.address 127.0.0.1 --server.port 8510
```

用用户名和密码登录。页面没有用户编号。

## 建议顺序

1. 公式页保存一条私有公式，例如 `close_hfq`，再点“用这个固定版本做因子研究”。
2. 因子研究页提交一段短区间。页面先显示作业编号。计算结束后再点“读取结果”。样本只有十几只时，IC 只能说明这一小段，不能外推。
3. 个人成本设置里保存一版。再保存一次会变成新版本，旧回测仍指向旧版本。页面上的万三和最低 5 元只是输入例子，不是市场规定。
4. 因子策略页看清只数、调仓、费用版本、区间和资金，再点一次“确认后运行回测”。成交在信号日的下一个交易日。图上是实费净权益和另一次零成本对照。表里还有同成交毛权益和累计费用。
5. 原策略页仍是动量、均线和财报 ROE。
6. 退出后再登录另一个用户。上一个用户的费用、评价和策略不会留下来。
7. AI 分析可以请它提交评价或估计一笔费用。长评价只返回作业编号，下一轮再问摘要。它不能保存公共策略，也不能改费用。
