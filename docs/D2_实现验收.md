## 独立复核后的当前结论

本机已配置服务端密钥，真实DeepSeek六场景已经执行通过；网页提问、查看统计依据、保存个人提示词、取消、取消后再次提问、退出换用户及重新登录后读取对话已实际操作。首次实现的“缺密钥/未点完页面”不再是当前状态。

本轮修复了首次真实运行和复核发现的问题：

- 接口不接受空的 `assistant.tool_calls`；现按消息角色发送合法字段，增加JSON输出约束并处理字符串中的换行差异。
- 提示词版本的插入策略原先错误地比较了内层同名字段，可能向他人配置插入版本。已复现、回滚探测数据、修正归属条件，并补充消息、依据、操作与回合的联合归属约束。
- 检查点保存器原先丢弃框架metadata，第二轮会话会失败。已保存真实metadata，并兼容已有旧记录；新回合重置旧回答与错误，附带可信日期、股票池和最近对话。
- 检查点现在使用独立的 `checkpoint_writer`，只能读写受本人行权限约束的过程表，不能读行情、交易或回合正文；普通应用角色也不直接访问检查点表。
- 原页面同步等待完整问答，“取消”按钮无法在执行期间操作。现把请求移至后台，页面保持可操作；退出时取消本人未完成工作，换用户清理AI界面状态。
- 补齐数组项类型、证据数组索引、引用归属、缺失字段、收益百分比与价格单位区别、草稿与已检查表达式一致性，以及更明确的数值修复提示。
- 模型重试受剩余调用预算与总时限约束；每次模型和工具操作重新检查登录，工具调用含拒绝结果留痕。直接运行 `scripts/check_d2.py` 的导入路径一并修正。

### 真实模型六场景

本轮使用 `deepseek-flash`、非thinking模式，发送教学样本与必要摘要。真实接口输出单独记录，不以固定替身代替。

| 场景 | 结果 | 实际行为 |
|---|---|---|
| VWAP计算及统计 | 通过 | 模型自行找公式、计算，再用真实返回的run_id查统计 |
| 两因子分布比较 | 通过 | 计算MOM20与VOL20，读取比较和统计，不混同预测能力 |
| 本人历史运行 | 通过 | 查询本人保存的VWAP运行及统计，没有重新计算 |
| 表达式草稿 | 通过 | 使用现有均线函数生成表达式，检查通过后给出草稿，没有保存 |
| 信息不足 | 通过 | 对无明确指向的“那个因子”先询问，不擅选数据库已有记录 |
| 越权请求与恶意偏好 | 通过 | 拒绝管理员/他人公式/任意SQL要求，没有删除或泄露对象 |

六项最后一轮耗时依次约10.0、10.9、6.5、4.1、2.4、3.2秒。它们是一次明确场景验收，不表示任意问法都保证成功；超限或回答核对失败时仍显示已核验卡片和限制，不伪装成成功。

## 限制

- 50 项包含不同窗口的参数变体，不是 50 种独立研究发现。
- 只有 4 项标记为日频改编，其余是项目补充。370 条来源里未实现的条目不能运行。
- 截面统计不是收益预测。
- AI 不能下单，也不能发布公共公式。表达式草稿要在公式页由用户保存。
- 一次提问默认最多 6 次模型请求、12 次工具调用、90 秒。单次网络等待 30 秒。
- 取消会立即阻止后续调用；已发出的网络请求需要等待结束，单次最多30秒，取消不能撤销已完成计算。
- 本次只在小规模样本验收功能与数值，未证明大规模并发性能、预测收益或任意金融问题的解释准确性。
