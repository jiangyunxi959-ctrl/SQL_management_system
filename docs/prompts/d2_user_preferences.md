# D2 用户可编辑的个人偏好模板

仅影响本人分析，不改变数据权限、日期和计算规则。建议用户在文本框中编辑以下内容，最多4000字符。保存生成新版本，下一次提问生效。

## 默认模板

```text
分析重点：先解释因子含义，再看有效数量、缺失原因和分布。
展示方式：中文，先给结论，再给最多五条依据；尽量用表格比较。
关注指标：有效比例、中位数、25%和75%分位数、样本标准差。
数据质量：如果历史不足、停牌或除权影响明显，先说明这些限制。
比较方式：同一天、同一股票池比较；不同单位分别解释，不硬排优劣。
表达式帮助：给出草稿后说明字段、窗口、单位和不能计算的情况。
```

## 可选示例

偏重流动性：

```text
优先关注成交额、量比、成交均价和非流动性。说明极端值是否来自成交额很小，以及有多少股票缺失。不要仅因数值大就称为更好的因子。
```

偏重趋势与波动：

```text
优先比较短期和中期涨幅与波动。先说覆盖情况，再解释窗口差异。需要跨日价格时说明采用的调整口径，不推断未来涨跌。
```

## 页面行为

显示当前配置名、版本、保存按钮和恢复默认按钮。内容只对本人可见，不能让用户选择别人的profile_id。未保存的编辑不影响当前执行；保存后下一回合启用。不要在界面要求用户填写数据库密码或模型密钥。
