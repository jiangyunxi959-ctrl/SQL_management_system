## 3. 已发现并修复的问题

| 问题 | 修复前的实际表现 | 修复与验证 |
|---|---|---|
| 特殊异常数值被接收 | 人为输入的 NaN 价格、成交额和调整因子没有被拒绝，进入正式数据 | 拒绝非有限数字；区分正常缺省和填写了无效内容；混合批次验证坏行拒绝、好行仍成功 |
| 部分错误价格拖垮整批导入 | 负的前收价格、停牌时的负开盘价导致整批失败 | 在导入前补全逐字段检查，并覆盖存储精度边界；不再让该坏行阻断好行 |
| 同一天的不同写法绕过重复检查 | 同一证券的 `2025-05-13` 与 `2025-5-13` 导致行情或调整因子整批失败 | 先识别实际日期，再判断重复；日期不同写法与完全相同写法均加入检查 |
| 页面可能悄悄切换操作账户 | 交易页选择第二个账户后，另一页面新增账户，下一次操作可能落到第一个账户 | 保留有效选择，按用户分开处理；新建账户后自动选中新账户；检查订单实际归属及切换用户 |

另补正一处波动程度说明，注明其已换算到年度口径。原计算本身正确。

前三项由 Terra 独立检查提出，随后实际复现；第四项在浏览器交叉操作时发现，并先用新增检查重现失败，再修复。不是根据猜测修改。
