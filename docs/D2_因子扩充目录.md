## 统一口径

- 收益率存小数；展示百分比只变换显示。成交额为元，成交量为股，不能拿“手”直接相除。
- 窗口按实际交易日计；lag 相对完整股票日序列，不能先过滤掉停牌或缺失日再移动。所需历史只预取到当前查询日期，不能向未来取数。
- 跨日价格收益采用现有同一调整口径；原价跨日窗口沿用除权保护。数据不足、分母零、停牌、异常值和缺失应给出原因，不补零。
- std 是样本标准差；窗口少于要求时无值。因子截面统计只统计有限有效值。
- 现有语法不增加新函数；50 条已通过当前 validate。上影/下影中的 abs 是为了表达 max/min 的数学等价式。
- 新增成交额分母后，须修正“单位含股数就判作零成交量”的粗略原因判断；根据实际字段来源区分成交量与成交额。

## 验收要求

每项公式必须用独立 Python 计算与数据库逐股票结果核对，不能用数据库自身公式作期望值。覆盖正常数据、边界日期、零量零额、缺失、停牌、历史不足、除权事件、单样本统计及用户隔离。对长窗口 120/250 日样本，必须使用足够长历史的真实行情副本；合成短样本全部缺失不能当作验收通过。

目录写入必须幂等，已有版本和运行保持不变。若已存在相同代码却内容不同，不静默覆盖：报告差异并按版本升级规则处理。新增 40 个只能在完成测试后注册，当前设计 JSON 不能被启动过程自动安装。
