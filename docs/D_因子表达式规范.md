# D 因子表达式规范 v1

状态：已由 `app/factors` 实现并用于公共和私有公式。2026-10-28。

本文规定公共因子与个人因子共同遵守的唯一计算语法。展示名称可以用中文；表达式采用下文列出的英文字段与函数。文字说明不是可执行表达式。

## 1. 公共和私有

- SYSTEM_PUBLIC：系统预定义，所有已登录用户可查看定义、表达式、版本、来源和说明，并运行或复制成私有公式。普通用户不能改写、删除或把自己的表达式设为公共。
- USER_PRIVATE：创建者本人可查看、修改、运行、归档；其他用户不能通过列表、搜索、编号查询、运行入口或结果表访问。
- 公共定义可以共用，个人运行参数、运行记录和结果默认仍然私有。
- 公共公式代码全局唯一；私有公式名称在同一用户内唯一。界面同时展示类别与名称，不会因私有公式与公共显示名称相同而选错。
- 编辑私有公式生成新版本，不覆盖旧版本。复制公共公式时保存完整表达式和来源版本，不跟随公共公式的后续变化。
- 第一版不在表达式中引用别的公式名称或编号；用户复制公共表达式后直接修改。避免隐藏依赖、循环引用和私有数据外泄。
- 本人归档只影响后续选择，不删除旧版本和旧运行记录；公共定义由受控系统维护入口发布。

## 2. 字段

| 字段 | 含义 | 单位/口径 |
|---|---|---|
| open_raw / high_raw / low_raw / close_raw | 当天开、高、低、收 | 元/股，未调整价格 |
| open_hfq / high_hfq / low_hfq / close_hfq | 当天开、高、低、收 | 元/调整后价格单位，沿用 B 的后复权口径 |
| volume | 当日成交股数 | 股 |
| amount | 当日成交额 | 元 |

不开放用户编号、账户余额、原始数据库对象名和任意财报列。后续开放财报字段时，必须先定义报告期、可用日及缺失语义，另发语法版本。

每个交易日每只股票最多一条输入，按交易日历对齐。日期、股票池、用户、公式版本由独立参数提供，不写进表达式。

## 3. 词法与语法

只允许 ASCII 字段、函数与符号；空白仅允许普通空格、Tab、CR、LF。名称区分大小写：字段及函数都必须小写。

数字允许非负十进制整数或小数，例如 `0`、`20`、`0.05`；负数通过一元负号表示。第一版不接受科学计数法、百分号、NaN、Infinity、字符串或日期字面量。字面量绝对值不超过 10^12，小数最多 12 位。

```ebnf
expression = sum ;
sum        = product, { ("+" | "-"), product } ;
product    = unary, { ("*" | "/"), unary } ;
unary      = ["+" | "-"], primary ;
primary    = number | field | "(", expression, ")" | call ;
call       = scalar, "(", expression, ")"
           | "lag", "(", expression, ",", integer, ")"
           | window, "(", expression, ",", integer, ")" ;
scalar     = "abs" | "log" | "sqrt" ;
window     = "ts_sum" | "ts_mean" | "ts_std" ;
number     = integer, [".", digit, {digit}] ;
integer    = "0" | nonzero, {digit} ;
digit      = "0" | nonzero ;
nonzero    = "1" | "2" | "3" | "4" | "5" | "6" | "7" | "8" | "9" ;
field      = 上表完整列出的字段之一 ;
```

乘除优先于加减；同级从左向右结合；括号改变顺序。不支持隐式乘法、幂运算、赋值、比较、逻辑运算、条件分支、数组、属性访问、注释、分号或多条表达式。筛选阈值、排序方向在独立筛选界面设置，不能偷偷写入公式。

## 4. 函数语义

| 函数 | 定义 |
|---|---|
| abs(x) | 绝对值 |
| log(x) | 自然对数，x 必须大于 0 且无单位 |
| sqrt(x) | 平方根，x 必须非负且无单位 |
| lag(x,k) | 同一证券之前第 k 个交易日的 x；k 为字面整数，1—251 |
| ts_sum(x,n) | 当前日及之前 n−1 个交易日的和 |
| ts_mean(x,n) | 当前日及之前 n−1 个交易日的算术均值 |
| ts_std(x,n) | 同一窗口的样本标准差，分母 n−1；n 至少为 2 |

求和、均值的 n 为字面整数，1—252。所有窗口必须完整，不忽略缺失值，不改用更早记录补齐。

允许一个窗口加一次向过去取值，如 `ts_mean(lag(volume,1),20)`；它表示之前 20 天均量，排除当天。也允许 `lag(ts_mean(volume,20),1)`。同一条计算路径最多一个窗口和一次 lag，禁止窗口套窗口及 lag 套 lag。

每条路径所需输入条数：字段为 1；lag 增加 k；窗口增加 n−1；普通运算取两侧最大值。最终最多 252 条。例如 `close_hfq/lag(close_hfq,20)-1` 要 21 条，`ts_std(log(close_hfq/lag(close_hfq,1)),20)` 也要 21 条。

表达式最长 1,024 字符，结构最多 32 个节点、深度最多 8。窗口参数不允许表达式、字段或小数，即 `ts_mean(volume,10+10)` 也拒绝。

## 5. 单位、价格和异常

- 编译阶段推导单位和价格口径。加减双方单位必须一致；无单位常数只与无单位值加减。乘除按单位组合，零常数不构成绕过检查的特例。
- 两种价格口径不能混合计算。`close_raw/close_hfq`、`amount/(close_hfq*volume)` 均拒绝；同口径价格相除得到无单位比值。
- `amount/volume` 识别为原始成交均价，可与原始价格比较；`amount` 是实际成交额，不能当作复权成交额。
- 对不涉及价格单位的量比、收益率，可以合法组合；不同已消去单位的收益率不因曾用过不同价格口径而一概禁止。
- 私有表达式不是筛选条件，最终结果必须是逐证券、逐日的数值序列。
- 非法语法、字段、函数、参数、单位或复杂度：保存即拒绝，返回错误位置与中文原因。
- 合法公式遇到无成交、缺数据、历史不足、分母为零、对数/平方根越界或非有限结果：对应结果为空，附原因，不改为 0，不令别的股票一同失败。
- 停牌日的价格和基于价格的因子为空；成交量或成交额只在存在可靠的零成交记录时保留 0。缺行不能当作停牌。
- 使用原始价格或股数的跨日比较与聚合，跨除权事件时保守标记 `CORPORATE_ACTION`；使用同日、无单位收益率作跨日统计不因此全部禁止。调整后价格的跨日收益沿用 B 的口径。
- 所有结果日终才完整可用；研究日期之后的输入不可见，信号用于下一交易日。不能通过负 lag、别名或函数绕过。

原因码至少包含 `INSUFFICIENT_HISTORY`、`MISSING_DATA`、`SUSPENDED`、`ZERO_VOLUME`、`DIVISION_BY_ZERO`、`DOMAIN_ERROR`、`NON_FINITE_RESULT`、`CORPORATE_ACTION`。上游已有原因应保留，多个原因记录明细；不能只剩一个无解释的空值。

## 6. 表达式示例

合法：

```text
amount / volume
close_raw / open_raw - 1
open_hfq / lag(close_hfq, 1) - 1
volume / ts_mean(lag(volume, 1), 20)
ts_std(log(close_hfq / lag(close_hfq, 1)), 20) * sqrt(252)
```

应拒绝：

| 输入 | 原因 |
|---|---|
| `lag(close_hfq,-1)` | 不允许未来取值或表达式形式的窗口参数 |
| `ts_mean(close_raw,20.0)` | 窗口必须是整数字面量 |
| `ts_mean(ts_mean(volume,5),20)` | 窗口嵌套 |
| `close_raw/close_hfq` | 两种价格口径混用 |
| `close_raw+volume` | 单位不一致 |
| `close_raw>10` | 筛选条件不属于因子表达式 |
| `system.vwap_d` | 不能引用对象属性或其他公式 |
| `amount/volume; DELETE FROM sim.account` | 多语句及数据库命令 |

## 7. 保存与计算流程

两种公式走相同的解析、校验和计算流程；公共公式也必须检查，不能免检。

保存原文、规范化结构、语法版本、内容摘要、单位、价格口径、最大历史长度和解释。使用固定映射生成数据库查询，禁止直接执行原始文本；保存时校验，运行时核对保存版本并复核结构，不信任客户端上送的校验标志。

版本一旦用于运行便不可改写；修改生成新版本。运行绑定明确的公式版本、真实用户、股票池、研究日期、数据依据和计算版本。内容摘要用于变化检测，不代替权限检查，也不代替原始数据备份。

第一版无截面标准化、去极值、方向自动翻转或统一乘 100。收益率 `0.05` 表示 5%，页面可格式化但不能改变保存值。所有预处理要显式记录，不能把参考文件中“标准化后再平滑”的因子误称为已经完整复现。

## 8. 必须通过的检查

1. 公共公式所有登录用户可读、可复制、可运行，普通用户不可修改；个人运行结果仍隔离。
2. 私有公式本人可管理；另一个用户无法列出、读取、运行或复制，AI 工具同样受限。
3. 所有公共公式符合本语法；所有上述拒绝示例被拒绝。
4. 使用小型可手算数据核对优先级、窗口、滞后、样本标准差、除零及错误位置。
5. 修改未来行情不改变过去计算；缺交易日不能被窗口自动跳过。
6. 公共公式复制后改变原公共版本，私有副本和旧结果不变。
7. 新定义安装重复执行不重复注册；代码与版本相同但表达式不同，应报冲突而非悄悄覆盖。
