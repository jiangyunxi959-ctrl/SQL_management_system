# BaoStock → 知时字段对照（B，10 月 25 日）

> 目的：今天先把“实际接口字段”和数据库字段对齐，避免后面按印象写 ETL。
> 数据源：BaoStock Python API（当前项目依赖锁定 `baostock==0.9.4`）。日线下载固定 `frequency="d", adjustflag="3"`，即**不复权日线**；复权单独使用 `query_adjust_factor()`。

## 1. 日线 `query_history_k_data_plus`

| BaoStock | 含义 | staging | 目标列 |
|---|---|---|---|
| `date` | 交易日 | `staging.daily_bar_raw.date` | `mkt.daily_bar.trade_date` |
| `code` | 证券代码 | `code` | `stock_code` |
| `open` | 开盘价 | `open` | `open` |
| `high` | 最高价 | `high` | `high` |
| `low` | 最低价 | `low` | `low` |
| `close` | 收盘价 | `close` | `close` |
| `preclose` | 前收价 | `preclose` | `pre_close` |
| `volume` | 成交量（股） | `volume` | `volume` |
| `amount` | 成交额（元） | `amount` | `amount` |
| `adjustflag` | 复权状态 | `adjustflag` | 不进入目标表；下载时必须为 `3` |
| `tradestatus` | 1 正常 / 0 停牌 | `tradestatus` | `is_suspended = (tradestatus='0')` |
| `isST` | 0/1 | `isST` | 先保留在 staging，供 A 推导 `ref.security_status` 区间 |
| `turn/pctChg/peTTM/pbMRQ/psTTM/pcfNcfTTM` | 派生/估值字段 | 原样落 staging | 今天不进入 `mkt.daily_bar` |

## 2. 复权 `query_adjust_factor`

| BaoStock | 含义 | 目标 |
|---|---|---|
| `code` | 证券代码 | `mkt.adj_factor.stock_code` |
| `dividOperateDate` | 除权除息日 | `ex_date` |
| `backAdjustFactor` | 累计后复权因子 | `back_factor` |
| `foreAdjustFactor` | 前复权因子 | 仅 raw 保留，不直接存 |
| `adjustFactor` | 本次复权因子 | 仅 raw 保留 |

ETL 会另外为每只有行情的证券在 `list_date` 补一条 `back_factor=1`，之后通过区间触发器维护 `[本次事件日, 下一事件日)`。
